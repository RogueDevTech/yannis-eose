# Staff profile redesign

## Goal
Full staff profile top-of-page redesign (not a chip rearrange). Keep brand blue as the identity surface.

## Layout
1. **Blue identity hero** — back + label; large avatar initials; name, email, frosted role/status/capacity chips; role description. Soft radial wash on brand blue.
2. **Action bar** under the hero (same card) — Refresh, Edit, Mirror, Reset, Deactivate. Mobile uses header kebab.
3. **Overview** card — `OverviewStatStrip` matrix (Last active, Sign-ins, Phone, Capacity).
4. **Account Information** card — unchanged data, same card chrome.
5. **Branches** card — company/branch badges.
6. **Details** grid — redesigned destination cards with title + short description + arrow.

## Out of scope
Modal bodies for marketing/funding/permissions/etc.
